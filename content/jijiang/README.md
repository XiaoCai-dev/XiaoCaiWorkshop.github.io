# JIJIANG

> AI Short Drama Workspace

Jijiang is an AI-powered workspace for producing short dramas — script to cut,
optimized for vertical formats and fast iteration.

## Why

Short drama is volume + speed: many episodes, tight hooks, cheap production.
Agent-driven generation fits the cadence in a way traditional pipelines can't.

## Status

Script and shot generation are in private alpha. The episode packer and
publishing layer are next.
